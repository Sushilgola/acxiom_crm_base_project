Secured REST API Specification

Role-authorized RESTful web services exposing CRM resources using JSON Data Transfer Objects (DTOs).

Authentication Endpoints
POST /api/auth/login Public / Rate limited
Authenticates user and returns active session/user DTO.
// Request Body
{ "username": "admin@acxiom.com", "password": "Admin@12345" }
POST /api/auth/logout Authenticated
Terminates authenticated session and writes audit entry.
Customer Resource API
GET /api/customers Authorized
Lists all customers scoped to user's permissions. Supports search query ?q=name.
POST /api/customers Authorized
Creates a customer record with server-side validation and duplicate prevention.
{
  "name": "Global Tech Corp",
  "email": "contact@globaltech.com",
  "phone": "9876543210",
  "company_name": "Global Tech",
  "status": "Active"
}
GET /api/customers/{id} Authorized
Retrieves single customer details by primary ID.
PUT /api/customers/{id} Authorized
Updates customer details; enforces server-side ownership authorization.
DELETE /api/customers/{id} Authorized
Deactivates or deletes customer record; logs audit event.
Leads, Deals & Pipeline Reports
GET /api/leads - List & search prospective leads.
POST /api/leads - Create a new lead record.
GET /api/opportunities - List sales deals and pipeline amounts.
POST /api/opportunities - Create sales opportunity (Amount > 0, Close Date >= Today).
GET /api/followups - List scheduled follow-ups and reminders.
GET /api/reports/pipeline - Returns stage-wise, owner-wise, and weighted pipeline values.
